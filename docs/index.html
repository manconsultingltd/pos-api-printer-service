Two print modes. You design the receipt.

No language detection and no country settings. One attribute on your print format decides how it prints.

Literal modeRecommended

Your print format controls every line. The service prints exactly what it renders.

  • Fiscal layouts and tax tables come through untouched
  • Alignment, bold and large text through simple CSS classes
  • Empty guarded sections leave no blank lines
<div data-print-mode="literal">
  ...
</div>

Modeled mode

The service recognizes a standard receipt and lays it out for you. Best for simple, uniform tickets.

  • Finds company, items, taxes, total, payments and change
  • Keeps the language of your receipt (Total, Totaal, Factura…)
  • Used when no attribute is set, so older installs keep working
<div data-print="fiscal">
  ...
</div>

A REST API you can call from anywhere.

JSON in and out. POSAwesome ships the client, but anything that can send an HTTP request can print.

POST /api/print-html
curl -X POST http://localhost:5058/api/print-html \
  -H "Content-Type: application/json" \
  -d '{"printer":"ThermalPrinter",
       "html":"<html>...</html>",
       "paper_width":58}'
GET /health and /api/printers
curl http://localhost:5058/health
# version and uptime

curl http://localhost:5058/api/printers
# list the system printers
POST /api/cash-drawer
curl -X POST http://localhost:5058/api/cash-drawer \
  -d '{"printer":"ThermalPrinter"}'
POST /api/test-print
curl -X POST http://localhost:5058/api/test-print \
  -d '{"printer":"ThermalPrinter",
       "paper_width":58}'

Up and printing in minutes.

Prebuilt, self-contained installers from CI, or run from source if you prefer.

  1. Download the installerGrab the .run (Linux) or .exe (Windows) from the GitHub Releases page. Fully self-contained, no Python on the target machine.
  2. Create the Print FormatSales Invoice, Custom Format on. Start the HTML with the API-print marker <!--API_PRINT_ESC_POS_THERMAL_80MM--> (or 58MM for narrow paper), then paste the literal 80mm example.
  3. Set it on the POS ProfileAssign the Print Format to your POS Profile. POSAwesome sees the marker and routes receipts to localhost:5058.
  4. Open the control panelVisit http://localhost:5058/ to pick your default printer, review the log and fire a test print. On Windows you can also use the tray icon.
