Welcome to the API Printer Service Installer

This package will install API Printer Service v1.0 on your Mac.

The service provides a local REST API on port 5058 that allows POSAwesome to send receipts directly to CUPS-managed thermal printers — faster and without opening a browser print dialog.

What gets installed:

  • Service runtime → /Library/Application Support/api-printer-service/
  • LaunchDaemon (auto-starts at boot) → /Library/LaunchDaemons/com.posawesome.api-printer.plist
  • Control panel app → /Applications/API Printer Service.app (opens the web UI at http://localhost:5058/)

Requirements: macOS 11 (Big Sur) or later, Intel or Apple Silicon. Python 3 must be available — install it with brew install python or xcode-select --install.

Administrator password is required. Click Continue to proceed.
